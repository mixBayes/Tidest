# Tidest

[English](README.md) · **简体中文**

macOS 菜单栏工具，用于切换窗口、快速排列窗口，以及把常用窗口的预览放到屏幕侧边。

同一个应用的多个窗口可以分别选择，包括 Finder 打开的不同文件夹窗口。

发布流程会在 GitHub Actions 中构建安装包，完成 Developer ID 签名、Apple 公证和构建来源证明，再通过不可变发布分发。首次配置与下载文件验证方法见[发布与验证](docs/RELEASING.md)。

## 功能

- **切换窗口**：用横向预览或可滚动的平铺列表浏览窗口，支持键盘、触控板和鼠标。
- **单窗布局**：把鼠标下的窗口放到半屏、四分之一屏，或铺满可用屏幕区域。
- **组合布局**：快捷键打开半透明全屏遮罩，直接在屏幕上分格、拖动分隔线和选窗，再一起排列。
- **停靠窗口**：把常用窗口的预览放在屏幕左侧或右侧，调整顺序，并选择哪些窗口关闭后仍可重新打开。
- **自定义**：各功能的快捷键均可修改；组合布局默认使用 Option + Shift + Q，界面支持英文、简体中文、繁体中文、日文和韩文。

## 开始使用

打开 Tidest，按引导开启权限。辅助功能权限用于切换和排列窗口；屏幕录制权限用于显示预览，可以按需开启。

| 功能 | 默认快捷键 |
| --- | --- |
| 切换窗口 | Option + Tab |
| 单窗布局 | Option + Q |
| 组合布局 | Option + Shift + Q |
| 停靠窗口 | Option + W |

在 **设置 → 窗口** 中修改快捷键。点击当前组合，按住 Control、Option 或 Command，再按另一个键；可同时加入 Shift。按 Esc 取消录入。快捷键冲突时保留原组合，菜单栏显示实际快捷键。

### 切换窗口

1. 按住 **Option**，再按 **Tab** 打开窗口面板。
2. 保持 Option 按住，每按一次 Tab 选择下一个；两个键一直按住时，每隔约一秒选择下一个。
3. 松开 Option 切换到选中窗口。

点击窗口预览可以直接切换。按 Esc 或点击面板外取消。

**横向预览**：在触控板或 Magic Mouse 上左扫选择下一个，右扫选择上一个。普通鼠标滚轮向下选择下一个，向上选择上一个。

**平铺预览**：鼠标移到截图上即可选中，上下滚动查看更多窗口；键盘选中屏外窗口时会自动滚入视野。

窗口按当前桌面上的前后顺序排列，选择最小化窗口时会先恢复。预览保留窗口自身比例，刷新后保留已选窗口和滚动位置。

### 单窗布局

按 **Option + Q**，把鼠标移到要排列的窗口露出的部分。点击布局图或按对应数字：

| 1 · 左上角 | 2 · 上半屏 | 3 · 右上角 |
| --- | --- | --- |
| 4 · 左半屏 | 5 · 铺满屏幕 | 6 · 右半屏 |
| 7 · 左下角 | 8 · 下半屏 | 9 · 右下角 |

四角各占四分之一。布局使用鼠标所在屏幕的可用区域，保留菜单栏和 macOS Dock。

松开 Option 后面板仍保留。按 Esc 或点击面板外取消。

### 组合布局

按 **Option + Shift + Q** 打开半透明全屏遮罩，可在 **设置 → 窗口** 修改快捷键。菜单栏仅显示当前快捷键提示，不可点击。清除快捷键后，需要先在设置中重新设置才能打开组合布局。旧 Option + Q 和已有自定义快捷键继续用于单窗布局。

1. 格子直接显示在唤起时鼠标所在的屏幕上，默认左右两栏。左上角直接横向展示空白布局、四个常用布局和已保存模板的缩略图，悬停显示名称；内容较多时可横向滚动。要在其他屏幕布局，请关闭后将鼠标移到那块屏幕再打开。
2. 靠近格子之间的分隔线时，线上会展开圆形拖动按钮，同时高亮所在线条。按钮沿线跟随鼠标，图标是双向箭头和中间的分隔虚线。按住拖动即可调整大小，格子始终铺满屏幕可用区域。分裂按钮附近优先响应按钮。水平边缘的按钮将格子分成上下两块，垂直边缘的按钮分成左右两块。
3. 鼠标移入格子时高亮。四边中点默认显示柔和的引导光，靠近某处时才展开该处的分裂按钮，移开后收回；原来的直边始终保留。按钮在悬停和按下时有高亮反馈。点击分裂时，弧线顶端的亮点分成两个光点，先沿现有曲线和边框抵达两侧端点；随后按钮收回，拖出分隔线并移到分格位置，新卡片再淡入。中央卡片右上角的删除按钮随格子悬停淡入淡出。点击格子打开窗口选择框。可以搜索应用或窗口标题，用方向键和 Enter 选择，Esc 关闭选择框；同一窗口只能分配一次。
4. 所有格子都有窗口后，点击左上方的 **应用** 或按一次 **Enter**，本次选中的所有窗口会排列并显示在前面。**取消、应用** 独立成组，与原工具栏相邻；点击 **取消** 或按 **Esc** 放弃本次编辑。选择框中的 Enter 只选窗口；松开后再按一次 Enter，才会应用布局。
5. 布局缩略图旁直接展示 **重置、保存模板、保存当前组合、回退** 四个图标，悬停显示名称。**重置** 恢复默认左右两栏并清空本次窗口选择；**回退** 尝试恢复上次应用前的真实窗口位置，没有可恢复记录时置灰。

选窗时，鼠标移入立即获取窗口画面，停留 120 毫秒后在列表旁显示缩略图；方向键选择也会同步预览，切换时淡入淡出。预览卡片为 320 × 240 逻辑点，完整展示原窗口，与选择框垂直居中、相隔 12 逻辑点，优先放右侧，靠近屏幕右边时放左侧。同一次组合布局中复用截图，刷新列表、换格子都不会重新截图；关闭组合布局后异步清理。不支持截图的窗口仍可正常选择。

按住格子中央的卡片拖动：拖到另一格中间交换窗口，拖到屏幕的左、右、上、下边缘移动整个格子，其余格子自动补齐。空格也能移动，已选窗口跟着格子保留。拖动时显示最终布局预览，松手确认；拖出布局后松手取消。“左一大、右两小”可把大格拖到右边，变成“左两小、右一大”，保留大格宽度和两小格的上下顺序。换方向时，原本占满该方向的格子使用一半空间；空间不足的排列不接受放置。

已有窗口选择的格子会在悬停时显示 **清除窗口选择** 图标，只清空当前格子的选择，保留格子。点击格子的 **删除格子** 图标后，相邻格子或相邻的一组格子扩展补满空位，其他窗口选择保留；最后一个格子不能删除。

编辑、选窗、重置和保存模板都不会移动真实窗口。在主预览按 Esc 取消。点击哪一边的分裂按钮，就在哪一边新增空格子，原窗口保留在另一边的老格子里，无需确认。更换布局或模板时，如已有窗口选择，会先确认清除；拖动比例不会清空选择。

**保存模板** 会预填“模板 1”等未使用的名称，也可以自行修改。如果布局与内置布局或已保存模板相同，会高亮对应缩略图并短暂提示，不再保存副本。模板只记录名称、分割结构和比例，不记录应用、窗口、标题、文件路径或显示器。右键点击工具栏中的模板缩略图可重命名或删除模板。可继续分格的范围由实际屏幕可用空间决定，格子过小时请删除格子或拖动分隔线调整大小。

保存模板后，布局缩略图会飞入工具栏中的模板位置。**保存当前组合** 只有在每个格子都选好窗口后才可点击，会同时保存格子比例和对应窗口；停靠栏先滑出，整组预览再飞入其中，成为一个已固定的停靠项目。重启 Tidest 后仍保留，点击项目可按保存的格子恢复整组窗口，已关闭的窗口沿用停靠栏现有的重开能力。保存时不移动真实窗口。开启系统“减少动态效果”时，保存动画改为淡入。

仅支持当前桌面中可移动、可缩放的普通窗口，可从已连接显示器选窗后统一排到目标显示器。最小化窗口、原生全屏窗口、其他 Space 和 Tidest 面板不参与。缺少屏幕录制权限时仍可使用图标和标题。

应用前会重新检查窗口、权限和显示器。各格子的高亮会从中央窗口卡片同时向外扩散，窗口同步排列，落位后高亮淡出。有尺寸限制的窗口会尽量按目标区域排列，保留调整结果；无法调整尺寸或暂时无法操作的窗口会静默跳过，其他窗口继续排列。执行结束后关闭预览，不显示结果或重试对话框。可按快捷键重新打开组合布局，点击工具栏的 **回退** 恢复之前的位置。回退会尽力恢复最近一次实际改变的窗口，不重开已关闭窗口。再次应用会替换最近一次可回退操作。

显示器拔出、分辨率或工作区变化会停止继续应用，需明确重新确认目标。撤销时原显示器配置变化会阻止使用旧坐标。需要在 macOS 上完成的构建和实机验收见[开发验证清单](docs/QUICK_LAYOUT_VALIDATION.md)。

### 停靠窗口

停靠窗口默认开启，停靠栏初始位于屏幕右侧。

1. 按 **Option + W** 开始选择要停靠的窗口。
2. 点击高亮窗口，拿起它的预览；原窗口留在原位。
3. 将预览移到停靠栏，再点击一次放下。
4. 点击停靠项目，把对应窗口带到最前面。

按 Esc 或再次按 Option + W 取消拾取。鼠标移到任意屏幕的停靠侧边缘时展开，移开后收起。多屏共用同一个列表；鼠标移到另一块屏幕的同侧边缘，停靠栏就会移过去，无需等待原来的停靠栏收起。

- **选择左右位置**：使用顶部换边按钮，或把顶部向屏幕内侧拖动一小段距离。
- **选择显示方式**：使用顶部控件，切换缩略图或“图标＋标题”。
- **调整顺序**：在栏内拖动项目。
- **移除项目**：拖出后松开，或右键选择 **从停靠栏移除**，原窗口仍然打开。
- **关闭后保留**：点击项目的 **保留** 图钉；窗口关闭后，点击项目即可重新打开。

所有停靠项目、顺序和左右位置都会在 Tidest 重启后恢复。未开启保留的项目随原窗口关闭而移除。停靠动画遵循 macOS 的 **减少动态效果** 设置。

| 应用 | 保留后重新打开的内容 |
| --- | --- |
| Finder | 新建窗口，打开保存的文件夹或“最近使用”位置 |
| macOS 终端 | 新建窗口，进入选中标签页保存的本地目录 |
| Chrome / Safari | 新建窗口，恢复保存的标签网址、顺序和选中标签 |
| 其他应用 | 打开应用本身 |

窗口仍在运行时，保存的文件夹、目录和标签页会跟随变化；重新打开使用最后成功保存的位置。

## 设置与权限

菜单栏的 **使用说明** 提供切换窗口、单窗布局、组合布局和停靠窗口的示意，快捷键跟随当前设置。可以暂停、重播、拖动进度条或点击步骤单独查看。拖动后停在所选位置，点击“继续播放”接着看。开启 macOS 的 **减少动态效果** 后，仍可拖动进度或点击步骤查看静态示意；查看说明不需要开启权限。

**设置 → 窗口** 包含预览方式、快捷键和停靠窗口开关；**设置 → 通用** 包含语言与权限。未手动选择语言时跟随系统语言，修改后立即生效。

菜单栏中，**使用说明** 下方的 **操作统计** 可查看今日次数、累计次数和最近 7 天的柱状图，移到图上会突出对应日期并显示次数。右下角的说明按钮可查看计数规则：成功切换窗口、完成单窗布局或整套组合布局、添加窗口到停靠栏、从停靠栏打开窗口，各计一次；取消、失败和仅打开面板不计。次数从支持统计的版本首次启动时开始累计，无法补回此前的使用记录。

| 权限 | 用途 |
| --- | --- |
| 辅助功能 · 必需 | 切换、移动和调整窗口大小 |
| 屏幕录制 · 可选 | 在切换窗口和停靠栏中显示截图 |
| 自动化 · 按应用授权 | 保存和重新打开保留窗口的文件夹、终端目录或浏览器标签页 |

未开启屏幕录制时显示应用图标和窗口标题，切换窗口、单窗布局与组合布局仍可使用。点击 **暂不开启** 可以继续，勾选 **下次不再提醒** 后不再重复提示。

Tidest 在启动或重新打开时检查权限，可以点击通用页的 **前往系统设置** 管理。读取或控制支持的应用时，macOS 会另行询问自动化授权。

## 本地数据与隐私

Tidest 每 24 小时在后台检查 GitHub 中的已签名更新列表，重启后沿用上次检查时间。发现新版后，在菜单栏图标和“关于”菜单项上显示升级标记，并在图标下方显示可点击的小气泡，同一版本在这台 Mac 上只提示一次。后台检查不会打开“关于”或弹出更新对话框，失败不影响操作。点击气泡进入“关于”后，直接显示已发现的版本和 **下载** 按钮；以后打开“关于”也会沿用本机保存的更新信息，不重复检查。关闭气泡或查看“关于”后，升级标记继续保留，成功更新后清除。

点击“下载”后，在 Tidest 内显示进度并可取消，Sparkle 会在开始下载时重新校验该更新。准备好后，可以选择 **重启并更新** 或 **稍后**。“稍后”会继续运行当前版本，之后可以在“关于”中重启更新，也可以在下次退出 Tidest 时完成更新。关闭“关于”不会取消下载。更新失败不影响当前版本继续使用。查看“关于”和检查更新不需要辅助功能权限，也不会发送设置或窗口记录。

更新使用 [Sparkle 2](https://sparkle-project.org/)，安装和重新打开应用所需的辅助程序随 Tidest 一起打包，无需另外安装。如果安装位置需要管理员权限，macOS 可能要求授权。没有内置更新器的旧版本，需要先手动安装一次包含更新器的新版本。

Tidest 将设置、窗口记录和使用次数保存在这台 Mac 上。正式版本默认向 PostHog 发送匿名日活信息，用于了解每天有多少个安装在使用；可以在 **设置 → 通用 → 发送匿名使用信息** 中关闭。

日活只在你打开面板或操作 Tidest 时记录，后台驻留不计入。按北京时间每天最多成功发送一次，重启后沿用本机保存的随机安装标识，多台 Mac 分别计算。发送内容仅包含随机安装标识、使用时间和应用版本，不包含窗口标题、截图、文件路径或浏览器网址，也不创建个人资料或根据 IP 推断位置。发送失败不会影响操作；一分钟后再次使用时可以重试，整天离线的使用不会自动补传。开发、测试和界面预览不向正式项目发送数据。

- **切换窗口预览**：只缓存在内存，退出 Tidest 后清除。
- **停靠窗口**：保存应用、窗口标题、身份、尺寸、顺序和最后一张预览，供重启后恢复。
- **已保留窗口**：支持时额外保存 Finder 文件夹、终端目录或浏览器标签网址。
- **设置与窗口记录**：使用 macOS 的 `UserDefaults`，即系统提供的本地设置存储。
- **使用次数**：仅保存每天的次数和统计开始日期，不保存操作明细，不上传。
- **日活标记**：本机保存随机安装标识和最近一次成功发送的北京时间日期，用于跨重启去重。
- **停靠预览**：以 PNG 保存到 `~/Library/Application Support/com.mixbayes.tidest/PinnedPreviews/`，移除项目时删除对应图片。

保存的预览可能包含窗口中的内容，浏览器网址也可能包含查询参数。分享截图、设置或诊断资料时，请留意这些内容。

## 从源码构建

当前工程要求 **macOS 14.0 或更高版本**，以 `tidest.xcodeproj` 中的配置为准，并需要支持工程所用 macOS 接口的 Xcode。Xcode 会自动获取固定版本的 Sparkle 2.10.1 依赖。

用 Xcode 打开 `tidest.xcodeproj`，选择 `tidest` scheme；需要签名时选择自己的开发者团队，然后运行。

也可以使用临时签名构建本地开发版本：

```sh
xcodebuild -project tidest.xcodeproj -scheme tidest -configuration Debug \
  -derivedDataPath /tmp/tidest-build -destination 'platform=macOS' \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build
```

应用位于 `/tmp/tidest-build/Build/Products/Debug/tidest.app`。

工程使用 SwiftUI 和 AppKit，通过辅助功能接口控制窗口，通过 ScreenCaptureKit 获取预览。为支持操作其他应用的窗口，关闭了 App Sandbox（应用沙盒），仍启用 Hardened Runtime（运行时保护）。正式分发需要 Developer ID 签名和公证。

### 测试与界面预览

运行测试：

```sh
xcodebuild -project tidest.xcodeproj -scheme tidest -configuration Debug \
  -derivedDataPath /tmp/tidest-build -destination 'platform=macOS' \
  -parallel-testing-enabled NO CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual \
  DEVELOPMENT_TEAM= test
```

Tidest 仅支持 macOS。几何、草稿、控制器和界面测试统一通过 macOS 上的 Xcode 运行。

测试包含窗口选择、滚动、快捷键、设置与权限、停靠保存与重开、预览存储和窗口布局。

Debug 构建提供开发用界面预览参数。预览使用示例窗口和独立设置，不申请权限，也不改变真实窗口。

| 预览 | 参数 |
| --- | --- |
| 权限引导 | `--ui-preview-accessibility` 或 `--ui-preview-screen` |
| 设置／关于 | `--ui-preview-settings` 或 `--ui-preview-about` |
| 使用说明 | `--ui-preview-usage`，可附加 `--ui-preview-usage-static` 查看静态步骤 |
| 更新状态 | `--ui-preview-about --ui-preview-update=<state>`，state 可选 `checking`、`up-to-date`、`available`、`failed` 或 `download-failed`；使用示例响应，不会打开浏览器 |
| 切换窗口 | `--ui-preview-switcher`，可附加 `--ui-preview-tiled`、`--ui-preview-count=150`、`--ui-preview-thumbnails` 或 `--ui-preview-refresh` |
| 单窗布局 | `--ui-preview-layout`，可附加 `--ui-preview-layout-constrained` |
| 组合布局 | `--ui-preview-multi-layout`，可附加 `--ui-preview-multi-layout-partial`、`--ui-preview-multi-layout-denied` 或 `--ui-preview-multi-layout-size-limits` 验证静默跳过 |
| 停靠窗口 | `--ui-preview-pinned`，可附加 `--ui-preview-count=20` |
| 预览语言 | `--ui-preview-language=<code>`，code 可选 `en`、`zh-Hans`、`zh-Hant`、`ja` 或 `ko` |
| 设置预览中的已开启权限 | `--ui-preview-granted-accessibility` 和 `--ui-preview-granted-screen` |
