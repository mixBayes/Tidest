## What's new

- Fix Option + Q not opening Single-window layout while using the built-in macOS screen recorder.
- Add an application animation to Combined layout: highlights expand together from the central window cards, settle at the actual window positions, and fade out.
- Place windows with size limits as close as possible to their target regions. Windows that cannot be operated are silently skipped while the remaining windows continue, without error or retry dialogs.

## 更新内容

- 修复使用 macOS 自带录屏时，Option + Q 无法唤出单窗布局的问题。
- 组合布局新增应用动画：各格子的高亮从中央窗口卡片同时向外扩散，衔接窗口实际位置后淡出。
- 有尺寸限制的窗口尽量按目标区域排列；无法操作的窗口静默跳过，其他窗口继续排列，不再显示错误或重试对话框。
