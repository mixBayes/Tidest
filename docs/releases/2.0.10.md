## What's new

- Arrange several windows together: split the screen, resize regions, and drag cards to swap windows or move regions.
- Save layout templates and window groups for reuse, with window previews and a quick way to restore the previous arrangement.
- Refresh the app icon and shortcut hints, and improve window placement animations and preview selection.

## 更新内容

- 新增组合布局：分格、调整大小、拖动交换窗口或移动格子，一次排列多个窗口。
- 支持保存布局模板和窗口组合，选窗时查看预览，并可回退上次排列。
- 更新应用图标和快捷键提示，改进窗口落位动画与预览选择。
