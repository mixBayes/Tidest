## What's new

- Download updates inside Tidest, with progress, cancellation, and the option to restart later.
- Check for updates in the background and show a menu-bar reminder once per version.
- Optional anonymous usage reporting, without window contents. Turn it off in General settings.

Versions 2.0.8 and earlier need one manual installation of this version.

## 更新内容

- 支持应用内下载更新，可查看进度、取消下载或稍后重启。
- 后台检查新版并在菜单栏提醒，同一版本仅提示一次。
- 新增匿名使用统计，不包含窗口内容，可在通用设置中关闭。

2.0.8 及更早版本需手动安装一次本版本。
