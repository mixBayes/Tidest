# 窗口定位与多窗口快速布局：开发验证与交接

这是窗口定位与快速布局的实现和验证记录。Tidest 仅支持 macOS，测试通过 Xcode 运行。

## 范围和产品默认值

基准为 `mixBayes/Tidest` 的 `81495a2`，分支为 `feat/window-positioning-quick-layout`。旧 Option + Q 功能的界面名称改为“窗口定位”，`quickLayoutShortcut` 等旧配置键保留。窗口切换和 Dock/Keep 的实现不变。

按需求提案的推荐方案实现：四个常用起点（左右、上下、左大右两小、四宫格）及独立空白入口。左大区域默认占三分之二；新快速布局的快捷键默认为 Option + Shift + Q（可修改或清除），菜单入口始终可发现，设置中独立配置并检查冲突。


按用户确认的交互修订为半透明全屏遮罩：格子与实际屏幕可用区域一一对应；拖动共享分隔线，始终铺满；水平边缘按钮上下分裂，垂直边缘按钮左右分裂；鼠标移入格子高亮，点击弹出选窗框；应用和取消位于右上角。左上角保留布局起点、模板、显示器选择和更多操作。四边中点默认显示柔和引导光，分裂按钮隐藏；鼠标进入某处引导光周围 44 逻辑点时，仅该处展开圆润的内侧弧线和按钮，移开后收回，原有直边始终保留。按钮本身悬停提亮、按下加深底色并轻微缩小图标。展开和淡入淡出用 0.18 秒；中央卡片右上角的删除按钮继续随格子悬停用 0.15 秒淡入淡出，均尊重系统“减少动态效果”。共享直边只绘制一次，重合引导光也只显示一次，边线仍可拖动。删除单格后由相邻格子或相邻分组扩展填满，保留其他选择，支持撤销且不能删除最后一格。
采用二分树编辑。只能合并两个直接子叶区域；嵌套区域需先逐层合并。拖动共线且相接的分隔线会协调移动，并提供四分之一、三分之一、二分之一等比例吸附。分隔线支持辅助功能增减操作。

没有固定的产品格子数上限。当前可操作尺寸默认是实际显示器每区至少 160 × 100 逻辑点；二分比例限制为 10%–90%。已知窗口最小尺寸会额外阻止应用，窗口未报告的限制在执行后核验。过小的已保存模板必须编辑后再应用。持久化结构还有深度/节点校验，防止损坏输入。

模板名称最多 60 个字符，不允许不区分大小写的重名。模板仅保存标识、名称、分割结构和比例。窗口选择、目标显示器和最近一次应用的撤销记录只存在内存。候选使用应用图标和标题，不依赖截图权限；刷新约每 1.5 秒触发一次读取，以更新失效窗口，键盘高亮按窗口身份保留。

预览期间不写 AX、不还原最小化窗口。当前候选仅限当前桌面上可移动、可缩放的普通窗口，排除最小化、原生全屏、其他 Space 和 Tidest 自身。整批应用先预检，再逐窗复检和执行。位置与尺寸按逻辑坐标和目标缩放计算，兄弟区域共享取整后的边界。

应用完成后复用窗口定位的激活接口，把成功排列的窗口显示在前面。全部成功关闭预览，菜单提供“撤销上次快速布局”；部分成功保留逐窗结果，可只重试失败项或撤销。草稿撤销与真实应用撤销分开。原始几何来自首次写入前的整批快照，失败或取消的已尝试窗口也保留撤销信息；撤销遇到已关闭窗口会继续恢复其余有效项。显示器变化取消剩余操作，各次 AX 写入前再次检查物理显示器拓扑；配置发生变化后禁止使用旧坐标撤销。

本次未加入镜像/旋转、最近模板记忆、跨 Space、启动应用或窗口组合恢复；这些仍是需求提案中的待评审项或范围外项。

## 悬停与删除修订验证

已按用户确认改为悬停高亮，点击仅打开选窗框；按钮在悬停时淡入、移开时淡出，隐藏后不接受点击。截图确认鼠标移到右格时，仅右格高亮并显示按钮。随后按用户要求将删除按钮移入中央卡片右上角，并将分裂按钮与边线画成连续轮廓；较矮或较窄的格子使用紧凑卡片，避免与边缘按钮重叠。

删除复用现有分割结构：仅移除目标格子及其窗口选择，把相邻格子或相邻分组扩展到原父区域。测试覆盖删除后仍铺满、剩余选择与分割比例不变、选中项有效、最后一格不可删除、撤销恢复全部结构和选择，以及 220 轮混合编辑无重叠、空洞或越界。未改真实窗口排列引擎。

悬停与删除逻辑修订时，32 项相关单元测试和当时的 10 项快速布局界面测试通过；五种语言文案及 Git patch 检查通过。

上一轮中央删除按钮与边框融合修订，11 项快速布局界面测试全部通过，未重复运行未改动的业务模型单元测试。首轮发现刚分裂后按钮横向滑动，导致快速点击落空；改为固定点击区域，仅动画边线隆起和按钮透明度，原失败用例随完整界面测试通过。最终截图确认删除位于中央卡片内，外边和共享边均连续包住分裂图标，没有直线穿过按钮。已用相同开发者签名替换并启动本地应用，保留替换前的备份。

## 分裂光点动画修订

按用户最终补充的动作实现：从按钮内侧弧线顶端出现亮点，分成两个光点，先贴着现有曲线走到弧线两端，再沿原边框到达两侧端点。这一阶段保留原按钮和弧线，光点轨迹使用与按钮完全相同的曲线控制点。两点到达后，按钮收回，分隔线才从原边向最终位置移动，随后光点淡出、新卡片淡入。上下分格时光点去左右边框，左右分格时去上下边框。沿曲线及边框行走约 0.46 秒，拖出分隔线约 0.3 秒，卡片随后用 0.16 秒淡入；系统开启“减少动态效果”时直接显示分格结果。

动画由确认后的草稿分裂结果驱动。取消清除选择确认、区域过小或分裂未成功时不播放动画；撤销、切换显示器可结束当前显示过程。未修改窗口排列服务。

按用户要求，本轮只编译生成本机版本，没有运行测试或自动检查动画效果。Xcode Debug 构建通过，已使用现有开发者签名替换并启动本机应用，旧版保留备份；实际动作和手感交由用户验收。

## 重现命令

在 Mac 上先构建，再运行单元测试和布局界面测试；如遇本机已有凭据或签名策略，按仓库原有构建说明处理，不修改签名或发布配置：

```sh
xcodebuild -project tidest.xcodeproj -scheme tidest -configuration Debug \
  -derivedDataPath /tmp/tidest-build -destination 'platform=macOS' \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= build

xcodebuild -project tidest.xcodeproj -scheme tidest -configuration Debug \
  -derivedDataPath /tmp/tidest-build -destination 'platform=macOS' \
  -parallel-testing-enabled NO -only-testing:tidestTests \
  -only-testing:tidestUITests/MultiWindowLayoutUITests \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= test

python3 scripts/check-layout-localizations.py
git diff --check
```

移除 `-only-testing` 参数可运行完整测试套件；本次没有完成完整界面测试套件。

Debug UI 预览参数：`--ui-preview-multi-layout`；加 `--ui-preview-multi-layout-partial` 可模拟部分失败与仅失败项重试。两种参数均不操作真实窗口、不写正式设置、不申请权限。旧单窗口参数 `--ui-preview-layout` 保留。

## 最小 macOS 实机验收清单

需要一个已授权的 macOS 14+ 测试会话、至少四个普通应用窗口，以及多屏测试时的第二台显示器。执行前记录测试窗口的位置和大小。

1. **升级与入口**：用旧自定义 Option Q/Tab/W 配置及 Dock/Keep 数据启动；确认配置未重置。菜单与设置正确区分窗口定位/快速布局，新快捷键默认为 Option + Shift + Q，四个快捷键两两冲突都不得覆盖已有设置。
2. **预览隔离与键盘**：逐起点编辑、分格、拖比例、选窗、保存模板，确认全部真实几何和最小化状态不变。选择器 Enter 只选窗，按住 Return 不穿透；Esc 先退选择器、再取消；命名模板时 Return 不应用。
3. **结构与模板**：从空白得到三列/三行；嵌套只能从内向外合并。四宫格共线分隔线同步；拆分已分配区域可取消或确认，只清除受影响选择。保存、重命名、删除，重启读取模板时无窗口绑定；小显示器上的过小模板不可应用。
4. **窗口与权限**：同应用同标题的不同窗口可独立选，重复窗口显示占用区域且禁选。关闭已选窗口，约下一轮刷新后对应区要求重选。关闭屏幕录制权限仍能凭图标与标题完成排布。撤销辅助功能权限时停止执行并沿用权限引导。
5. **真实应用与失败**：四区填满后点击应用，只改变所选窗口；原生全屏、最小化和其他 Space 不成为候选。用已知不能缩小的窗口验证预检或执行后受限结果。模拟某应用失联/拒绝移动，确认每窗结果准确，重试不再次移动成功项。
6. **最近一次撤销**：全成功从菜单撤销，部分成功从面板撤销，恢复进入应用前的几何。关闭其中一个窗口后撤销，其他窗口仍应尽力还原。重试失败项之后仍用第一次应用前的基准。再次整体应用后只保留最新一次撤销。
7. **显示器与坐标**：测试单屏、双屏、负坐标、竖屏、1×/2×缩放、菜单栏与 Dock 的不同位置。鼠标跨屏不改变目标；显式切换才改目标。预览/执行中拔屏或改缩放，停止剩余操作并要求确认，不能把窗口悄悄排到其他屏。
8. **保留功能回归**：旧九宫格所有定位、重复操作、目标判定和退出；Option Tab 切换；Option W 拾取、顺序、显示方式；Keep 对 Finder 文件夹、Terminal 本地目录、Chrome/Safari 标签网址、顺序和选中标签的恢复。
